# Progress comparisons

Run `pnpm test-parity progress` to compare Angular Progress with pinned Base UI in Chromium,
Firefox and WebKit. Cases cover clamping, non-finite values, localized text and custom ARIA,
label replacement, LTR and RTL layout, and SVG stroke geometry.

The [Progress matrix](../../../../packages/primitives/progress/PARITY.md) records the Angular
range fallback, numeric data attributes and SVG styling contract.
