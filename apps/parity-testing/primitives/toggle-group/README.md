# ToggleGroup comparisons

Run `pnpm test-parity toggle-group` to compare Angular with the pinned Base UI ToggleGroup in
Chromium, Firefox and WebKit. Cases cover defaults, controlled ownership, single and multiple
selection, shared cancelable details, roving focus and automatic Toolbar composition. Cases also
cover generated identities, disabled custom hosts, runtime changes to `multiple`, and reordering,
removing and reinserting items.

The [ToggleGroup matrix](../../../../packages/primitives/toggle-group/PARITY.md) describes Angular
Forms and native submission coverage.
