# ToggleGroup comparisons

Run `pnpm test-parity toggle-group` to compare Angular with the pinned Base UI ToggleGroup in
Chromium, Firefox and WebKit. Cases cover initial and late defaults, the precedence of an
explicit empty selection, and a parent holding, accepting and replacing a requested value.

The [ToggleGroup matrix](../../../../packages/primitives/toggle-group/PARITY.md) describes Angular
Forms and native submission coverage.
