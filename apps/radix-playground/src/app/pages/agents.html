How it works

The buttons run built-in commands against the form. A local executor can give a model access to the same commands for registered controls in the running demo.

Run with Codex locally

This runs a real Codex model against a local copy of the demo. Have Node 24, pnpm, and Codex CLI ready. Use your existing checkout or clone the repository below.

  1. Start the site

    git clone https://github.com/radix-ng/primitives.git
cd primitives
pnpm install
pnpm exec playwright install chromium
pnpm build-site
pnpm exec http-server dist/radix-site -a 127.0.0.1 -p 4496 -c-1

  2. Run the rename scenario

    Leave the site running. Open a second terminal in the repository, sign in to Codex with ChatGPT, and replace YOUR_CODEX_MODEL_ID with a model available to your account. 

    codex login
pnpm agent:run --provider codex --scenario rename --model YOUR_CODEX_MODEL_ID

    The executor writes the result to dist/agent-testing/ .
