# Skills

#### Give a coding agent Radix NG documentation and examples.

The `radix-ng` and `radix-ng-examples` skills bundle API and styling contracts plus example source
for building your application's Angular components on the primitives.

```bash
npx skills add radix-ng/primitives/skills
```

Continue with [Agents — Getting started](?path=/docs/agents-getting-started--docs) for version checks
and a starter prompt. [Build with Radix NG](?path=/docs/agents-build-with-radix-ng--docs) shows the
expected implementation and checks; [Reference](?path=/docs/agents-reference--docs) lists the exports.
