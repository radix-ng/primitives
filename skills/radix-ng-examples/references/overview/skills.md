# Skills

#### Give a coding agent Radix NG documentation and examples.

The `radix-ng` and `radix-ng-examples` skills bundle API and styling contracts plus example source
for building your application's Angular components on the primitives.

```bash
npx skills add radix-ng/primitives/skills
```

Continue with [Agents — Getting started](../agents/getting-started.md) for version checks
and a starter prompt. [Build with Radix NG](../agents/build-with-radix-ng.md) shows the
expected implementation and checks; [Reference](../agents/reference.md) lists the exports.
