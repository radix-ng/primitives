# Radix NG project knowledge

Use [the engineering map](../../../docs/engineering/README.md) to select the guide relevant to the task.

- Library boundaries and layout: [architecture](../../../docs/engineering/architecture.md).
- Runtime conventions and DI: [patterns](../../../docs/engineering/patterns.md).
- Shared composition: [composition](../../../docs/engineering/composition.md).
- Focus, pointer and popup details: [mechanism index](../../../docs/engineering/mechanisms.md), then only the matching note.
- A specific primitive family: [family notes](../../../docs/engineering/primitive-families.md).
- Form controls: [forms](../../../docs/engineering/forms.md) and the relevant rows in [Signal Forms readiness](../../../docs/engineering/signal-forms-readiness.md).
- Builds, releases and CI: [deployment](../../../docs/engineering/deployment.md).

Use manifests/configuration for current versions and commands, source for the implemented API, and accepted ADRs for intended design. Report a mismatch rather than silently choosing an outdated summary. Do not read every guide for a small change.
