# Floating overlay engine (ADR 0015–0017, 0023)

dismissal, focus, and scroll-lock were rewritten to Base UI's model over a **shared neutral floating tree** (`core/floating`: `RdxFloatingTree` + node / trigger registries + typed events), replacing the CDK overlay and the old process-global dismissable-layer stack. **Dismissal** is the `RdxDismiss` capability (ADR 0015) reading that tree; **focus** is `RdxFloatingFocusManager` (ADR 0017), which composes `focus-scope` and owns the coordinated policy set — trap, aria-hidden isolation, the `markOthers` marker that dismissal's outside-press guard reads, and initial / return / restore focus + close-on-focus-out; modal pointer-blocking is a cut-out `RdxInternalBackdrop` (`setupInternalBackdrop`) instead of a body `pointer-events` toggle; **scroll-lock** is the ADR 0016 port. The focus manager is Accepted and in production for dialog, popover, menu, and select (plus context-menu / menubar via menu); Combobox / Autocomplete adoption, the modal Popover backdrop, the full portal-focus bridge, and the Phase-5 verification matrix are the de-scoped remainder tracked in **ADR 0023**.
