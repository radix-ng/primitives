# Thin positioners (ADR 0012)

every `<name>-positioner.ts` **`extends RdxPopperContentWrapper`** rather than composing it via `hostDirectives`. The ~11 positioning inputs, the `placed` output, and the host bindings are **inherited** (declared once on the wrapper); per-primitive defaults live only in `provideRdxPopperContentConfig(...)`; `provideRdxPopperContentWrapper(SelfClass)` re-wires the DI alias + context (Angular doesn't inherit a base directive's `providers`). The wrapper emits the unified Base UI CSS vars (`--anchor-*`, `--available-*`, `--positioner-*`, `--transform-origin`) and `data-side`/`data-align`/`data-anchor-hidden` once for everyone; `legacyPopperVars('<name>')` keeps the deprecated `--radix-<name>-*` aliases for one release. **z-index belongs on the positioner** (the wrapper no longer copies the popup's z-index, so a positioner no longer requires an inner `RdxPopperContent`). This cut positioner code ~1045→409 lines and removed a docs-vs-runtime default-drift bug (combobox/autocomplete/select were publishing wrong defaults). The docs pipeline resolves the inherited config defaults in `api-contract.mjs` + the Storybook compodoc plugin.
