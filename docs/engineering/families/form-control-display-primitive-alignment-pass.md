# Form-control + display-primitive alignment pass

a later sweep brought the rest of the families to the Base UI contract (mostly BREAKING where `data-state`/extra attributes were involved):

- **Radio** — `data-checked`/`data-unchecked` (no `data-state`); ArrowUp/Left also _check_ (selection-follows-focus), item exposes `data-composite-item-active`; dead no-op keydown handler removed.
- **Switch** — the hidden `[rdxSwitchInput]` no longer carries `data-checked`/`data-unchecked` (Base UI's hidden input has none; state lives on root/thumb).
- **Slider** — removed `data-index` from `ThumbInput` (it's on `Thumb`); pointer-reason typed `'track-press' | 'drag'`.
- **Toggle** — removed the unused, non-Base-UI `RdxToggleVisuallyHiddenInputDirective` (BREAKING export removal); the item now passes the computed `nextPressed` boolean to the group (`toggle(value, nextPressed, …)`, single source of truth); non-native hosts emulate native-button keys (Enter on keydown, Space on keyup).
- **Checkbox** — root context is an explicit interface; `toggle()` marks the form control touched (standalone forms bug); dropped a redundant disabled alias.
- **Label / Field / Form** — SSR-stable ids via `injectId` (replaced module counters across field root/control/label/description/error and label); explicit context interfaces (Field + Form, replacing `ReturnType<typeof>`); Field's `aria-required`/`aria-disabled` gated to non-native controls only (native attrs convey it natively); Field control gained `data-dirty`/`data-touched`; `onFormSubmit` now carries `reason: 'none'`. The cross-control validity-attr batch (`invalid/errors/touched/dirty` + `touch` output) stays the tracked Signal Forms collision #4 (copy the `input` pilot), not an ad-hoc per-primitive fix.
- **Progress** — removed `data-state` from all five parts (boolean `data-complete`/`data-progressing`/`data-indeterminate` remain); explicit context interface; SSR-stable ids; indeterminate keeps `aria-valuemin/max` and announces `aria-valuetext="indeterminate progress"`; the value part is `aria-hidden` (no `aria-describedby` double-announce); `aria-labelledby` is register-on-mount so it never dangles.
- **Avatar** — context migrated from the legacy `InjectionToken`/`provideToken` to `createContext`; removed forced `role="img"` on the `<img>`; added `crossOrigin`/`srcSet`/`sizes` + the `image.complete` cached fast-path; `onLoadingStatusChange` no longer fires the initial `idle`. (Deferred: image enter/leave `data-starting/ending-style` — a transition-status feature on a non-mounting `<img>`.)
- **Scroll Area** — thumb gained `data-scrolling`; SSR-stable `rootId` via `injectId`; added the `apps/visual-regression` behavior spec (overflow metrics, focusable viewport, thumb tracking).
- **Separator** — emits `aria-orientation` for **both** orientations (Base UI + the repo's own menu/combobox separators), not just vertical.
- **Aspect Ratio** — switched from the `AfterViewInit` + `Renderer2` child-mutation padding-bottom hack to the native CSS `aspect-ratio` property (BREAKING: children fill the box themselves, e.g. `class="size-full object-cover"`).
- **Toolbar** — `rdxToolbarInput` conveys disabled via `aria-disabled` only (never native `disabled`; roving removal via composite `disabledIndices`) and blocks pointer interaction while disabled.
- **Number Field** — read-only now natively disables the stepper buttons (Base UI parity) and the invalid `aria-readonly` on `role="button"` was removed (`data-readonly` added); fixed the stories' duplicate-id label association; added the `apps/visual-regression` behavior spec (stepper click + press-and-hold). (Deferred: `onValueCommitted` `eventDetails` parity; the Field validity batch.)
