# Form is the top of the forms layer cake (Base UI `Form`)

`form` (`form[rdxFormRoot]`, its own secondary entry `@radix-ng/primitives/form`) rides the native `<form>`: maps server/external `errors` onto fields by `name` (clearing on user edit, emitting `onClearErrors`), intercepts submit (`onFormSubmit` with `FormData`-serialized values, focus the first invalid field), resets field interaction state on native reset, and exposes aggregate `data-invalid`/`data-dirty`/`data-touched`/`data-submitting`. It owns no values or validation and never `stopPropagation`s, so Reactive Forms' `(ngSubmit)` still fires alongside. **Dependency direction is `field → form`** (Field optionally injects the Form context and registers through structural `() =>` accessors; `form` imports nothing from `field`) — the same acyclic cross-entry constraint as the checkbox/checkbox-group co-location, solved here by keeping the registration interface Form-side. Field has a `name` input, external-error merge, edit-forwarding, `RdxFieldError.messages()`, and an `RdxFieldState` provider seam. The explicit same-host `rdxNgControlField` adapter feeds Reactive/template-driven `NgControl` state into that seam and may infer the field name; the explicit root name wins. `rdxSignalField` uses the same seam, while `rdxSignalForm` uses Form's parallel `RdxFormState` seam. Field/Form still run no validation. No new runtime peer — the `field → form` edge remains internal and acyclic.
