# Parity matrix index

All **58 secondary entry points** have a matrix. **Eleven families** have dedicated comparison suites
against Base UI **1.9.0** at `cf696d6f6e08c699c5bda24d5a033430909f2285`. The suite READMEs and coverage map
record the scenarios and reviewed differences. The other matrices start from an API inventory and
identify the comparisons each family needs.
[Pinned suites and browser coverage](../../apps/parity-testing/COVERAGE.md).
[Reference preparation](upstream-reference.md).

**Breaking changes are permitted.** The
[state ownership and defaults contract](state-ownership.md) applies to each field. Parent-owned UI
state, editable form values, readonly configuration and native or derived state have separate owners.

## State/defaults migration queue

| Boundary               | Families / mechanisms                                                                                                                    | Required separation                                                                                                                                                        |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Popup and UI requests  | Dialog/AlertDialog/Drawer, Popover, Preview Card, Tooltip, Menu, Navigation Menu, Accordion, Tabs, Stepper/Pagination, standalone Toggle | Supplied UI state owns rendering; accepted request outputs do not themselves prove a controlled commit. Initial defaults are snapshots, including false/empty cases.       |
| Mixed Roots            | Combobox/Autocomplete/Select; Drawer snap/drag; Calendar date/navigation                                                                 | Audit each value separately. Form value can remain a model while open/selection requests use a parent-owned contract; previews/drafts/gesture state need a distinct owner. |
| Forms                  | Input, Checkbox/Group, Radio, Switch, Slider, Number/OTP/Date/Time fields, Editable, Toggle Group, Signal Forms/native adapters          | Preserve required model inputs; initial parent/CVA/Signal Forms writes precede defaults. Specify accepted edits, reset baseline, normalization and dirty/touched timing.   |
| Readonly/configuration | Meter/Progress, Field/Fieldset metadata, direction/config, Separator/Arrow/Aspect Ratio                                                  | Configuration/input defaults may be reactive. Do not invent a writable form value or freeze updates under a one-shot state-default rule.                                   |
| Shared implementation  | Core, Composite, Popper, Presence, Portal, dismissal and focus mechanisms                                                                | Derive geometry/registry/lifetime/focus from effective state. Reuse small Angular-owned mechanisms; ignored requests must not cause committed side effects.                |
| Native/async services  | Scroll Area, hidden native inputs, Avatar loading, Toast queue                                                                           | Native DOM or request/service generation owns state. Specify async cancellation, baseline/reset and completion without another Root model mirror.                          |

## Evidence discipline and maintenance

- A paired suite establishes the scenarios recorded in its README. Use the family matrix to find
  gaps beyond that scenario set.
- Initial matrices inventory exported decorated classes, direct input/model/output declarations,
  related pinned exports and existing test/fixture locations. Host composition and inherited surfaces
  still need detailed API comparison; per-handler/state-attribute equivalence remains pending.
- Date source observations and diagnostic probes in the family matrix. Record paired scenarios with
  the engines run and any reviewed exceptions. Use test-file links and screenshots to locate coverage.
- For Angular extensions and infrastructure without a direct public counterpart, record the native,
  Angular or shared-mechanism contract; do not invent missing Base UI parts or claim zero parity.
- Add scenario/engine evidence and reviewed differences as work lands. Preserve current matrices
  while adding new ones; avoid duplicating this policy or changing the pin silently.

Format changed Markdown, run `pnpm agents:check` and verify links in the family matrices. Follow the
[consumer skills pipeline](consumer-skills.md) when changing public API, examples or MDX.
