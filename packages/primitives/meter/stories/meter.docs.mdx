# Meter

#### A graphical display of a numeric value within a range.

<Canvas sourceState="hidden" of={MeterStories.Default} />

## Features

- ✅ Exposes meter semantics with `role="meter"` and `aria-valuenow`.
- ✅ Supports custom `min` and `max` ranges.
- ✅ Formats display text with `Intl.NumberFormat`.
- ✅ Provides Label and Value parts for accessible naming and value text.
- ✅ Mirrors value metadata through `data-value`, `data-min`, `data-max`, and `data-percent`.

## Import

```typescript
import {
  RdxMeterRootDirective,
  RdxMeterLabelDirective,
  RdxMeterValueDirective,
  RdxMeterTrackDirective,
  RdxMeterIndicatorDirective
} from '@radix-ng/primitives/meter';
```

## Anatomy

```html
<div rdxMeterRoot [value]="24">

  <div rdxMeterTrack>

  </div>

```

## API Reference

### Root

`RdxMeterRootDirective`

<ArgTypes of={RdxMeterRootDirective} />

The default announced text is the localized percentage. Use `format` to display a localized
number based on the clamped value. Pass `getAriaValueText` to derive an announcement from the formatted text and the
original supplied number. An explicit `aria-valuetext` takes precedence.

### Label

`RdxMeterLabelDirective`

Gives the meter its accessible name through `aria-labelledby`. Apply to a `<span>`. The Root follows
the mounted part and its current ID. An authored `aria-labelledby` takes precedence.

<ArgTypes of={RdxMeterLabelDirective} />

### Value

`RdxMeterValueDirective`

Displays the formatted value text on a visual element such as a `<span>`. The Root announces the
value, so this part is hidden from assistive technology. Use `getValueText` to customize the visible
text using the formatted text and the original supplied number.

<ArgTypes of={RdxMeterValueDirective} />

### Track

`RdxMeterTrackDirective`

Contains the visual indicator and mirrors root value attributes.

### Indicator

`RdxMeterIndicatorDirective`

Displays the visual meter fill. On an HTML element it sets the percentage width, inherits the
track's height and sets `inset-inline-start: 0` for positioned layouts. SVG hosts use authored
geometry, which can read `data-percent`.

## Data attributes

| Attribute      | Parts                         | Value                                    |
| -------------- | ----------------------------- | ---------------------------------------- |
| `data-value`   | Root, Value, Track, Indicator | The current numeric value.               |
| `data-min`     | Root, Value, Track, Indicator | The minimum value.                       |
| `data-max`     | Root, Value, Track, Indicator | The maximum value.                       |
| `data-percent` | Root, Value, Track, Indicator | The current percentage within the range. |
