# Switch

#### A control that allows the user to toggle between checked and not checked.

<Canvas sourceState="hidden" of={SwitchStories.Default} />

## Features

- ✅ Can be controlled or uncontrolled.
- ✅ Full keyboard navigation.
- ✅ Supports disabled, read-only and required states.
- ✅ Native form submission, constraint validation, and reset.

## Import

```typescript
import { RdxSwitchRoot, RdxSwitchThumb } from '@radix-ng/primitives/switch';
```

The API follows [Base UI Switch](https://base-ui.com/react/components/switch) with a `Root` and
`Thumb` on consumer-provided elements.

## Anatomy

```html
<button id="alerts" rdxSwitchRoot name="alerts" [(checked)]="checked">
    <span rdxSwitchThumb></span>
</button>
<label for="alerts">Alerts</label>
```

The root creates a native checkbox beside the button after browser rendering. The input supplies
native `required` validation and bubbling `input` and `change` events. Set `name` for form submission,
`form` for an explicit form owner, and `uncheckedValue` to submit a value in the off state.

## Examples

### Preselection

Set `defaultChecked` to start in the on state. The initial `checked` binding or Angular Forms value
takes precedence over this default. Later changes to `defaultChecked` leave the current state and
native reset baseline intact.

## Change events

`onCheckedChange` emits `{ checked, eventDetails }`. Use `eventDetails.cancel()` to reject a
state change before the switch updates. Use `[(checked)]` for an editable model and
`[controlledChecked]` when the parent accepts or ignores each request.

```html
<button [controlledChecked]="checked()" (onCheckedChange)="setChecked($event)" rdxSwitchRoot>
    <span rdxSwitchThumb></span>
</button>
```

```ts
setChecked(change: RdxSwitchCheckedChangeEvent) {
    if (this.locked()) {
        change.eventDetails.cancel();
        return;
    }

    this.checked.set(change.checked);
}
```

## API Reference

### Root

`RdxSwitchRoot` — the switch itself. Apply to a native `<button>` element. Exposes `role="switch"`,
`aria-checked`, and mirrors `aria-required` / `aria-readonly`. Use `nativeInput()` or `[inputRef]` to
access the active native input.

<ArgTypes of={RdxSwitchRoot} />

**Data attributes**

| Attribute        | Present when            |
| ---------------- | ----------------------- |
| `data-checked`   | the switch is on.       |
| `data-unchecked` | the switch is off.      |
| `data-disabled`  | the switch is disabled. |
| `data-readonly`  | the switch is readonly. |
| `data-required`  | the switch is required. |

### Thumb

`RdxSwitchThumb` — the moving indicator. Apply to a `<span>` element. Reads everything from context; it
has no inputs.

**Data attributes**

| Attribute        | Present when            |
| ---------------- | ----------------------- |
| `data-checked`   | the switch is on.       |
| `data-unchecked` | the switch is off.      |
| `data-disabled`  | the switch is disabled. |
| `data-readonly`  | the switch is readonly. |
| `data-required`  | the switch is required. |

### Input

`RdxSwitchInput` is an authored native checkbox for templates that supply their own input. An
authored input in the Root's context takes precedence and is included in server-rendered HTML.

## Accessibility

Adheres to the [`switch` role requirements](https://www.w3.org/WAI/ARIA/apg/patterns/switch).

### Keyboard Interactions

| Key     | Description                    |
| ------- | ------------------------------ |
| `Space` | Toggles the component's state. |
| `Enter` | Toggles the component's state. |
