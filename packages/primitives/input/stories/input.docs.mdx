# Input

#### A native text input with headless state attributes and Field integration.

<Canvas sourceState="hidden" of={Stories.Default} />

## Features

- ✅ Works as a standalone native input.
- ✅ Integrates with Field labels, descriptions, errors, and state.
- ✅ Supports controlled value, default value, disabled, required, and invalid states.
- ✅ Exposes state through data attributes for styling.

## Import

```ts
import { RdxInputDirective } from '@radix-ng/primitives/input';
```

## Anatomy

Use `rdxInput` directly on a native input. Wrap it in Field when you need label, description, and error relationships.

```html
<div rdxFieldRoot>
  <label rdxFieldLabel>Email</label>
  <input rdxInput />
  <p rdxFieldDescription>Used for account notifications.</p>
  <p rdxFieldError>Enter a valid email address.</p>
</div>
```

## API Reference

<ArgTypes of={RdxInputDirective} />

**Data attributes**

| Attribute       | Present when                                  |
| --------------- | --------------------------------------------- |
| `data-invalid`  | Displayed validation is invalid.              |
| `data-valid`    | Displayed validation is valid.                |
| `data-disabled` | The input or its Field is disabled.           |
| `data-required` | The input or its Field is required.           |
| `data-readonly` | The input is read-only.                       |
| `data-filled`   | The input contains a value.                   |
| `data-focused`  | The input is focused.                         |
| `data-touched`  | The input has been touched.                   |
| `data-dirty`    | The value has changed from its initial value. |

Inside Field, `validationMode` can leave displayed validation neutral: both `data-valid` and
`data-invalid` are then absent. Use `rdxInput` directly; it already integrates with Field and does
not need `rdxFieldControl` on the same element.
