# Accordion

#### A vertically stacked set of interactive headings that each reveal an associated section of content.

<Primary />

## Features

- ✅ Native button keyboard interaction (`Space` / `Enter`) with browser tab order.
- ✅ Base UI state hooks: `data-open` / `data-panel-open` plus enter/leave `data-starting-style` / `data-ending-style`.
- ✅ Exposes horizontal/vertical orientation state for styling.
- ✅ Expand a single item or multiple items at once (`multiple`).
- ✅ Can be controlled or uncontrolled.
- ✅ Cancelable `onValueChange` (root) and `onOpenChange` (item) events carry an `eventDetails` payload.
- ✅ Exposes the panel size as `--accordion-panel-height` / `--accordion-panel-width` for animations.
- ✅ Keep collapsed panels mounted (`keepMounted`) or findable by browser search (`hiddenUntilFound`).

## Import

Get started with importing the directives:

```typescript
import {
  RdxAccordionRootDirective,
  RdxAccordionItemDirective,
  RdxAccordionHeaderDirective,
  RdxAccordionTriggerDirective,
  RdxAccordionPanelDirective
} from '@radix-ng/primitives/accordion';
```

## Anatomy

```html
<div rdxAccordionRoot>
  <div rdxAccordionItem>
    <div rdxAccordionHeader>
      <button rdxAccordionTrigger></button>
    </div>
    <div rdxAccordionPanel></div>
  </div>
</div>
```

## Examples

### Disabled

Disable the whole accordion via `disabled` on the root, or a single item via `disabled` on the item.

### Multiple

Set `multiple` to let several items stay open at once.

<Canvas of={AccordionStories.Multiple} />

### Collapsible

In single mode the open item can always be closed by clicking its trigger again (Base UI parity —
there is no separate `collapsible` input).

<Canvas of={AccordionStories.Collapsible} />

### Horizontal

Set `orientation="horizontal"` to expose horizontal state for styling. Following the APG guidance update adopted by Base UI, orientation no longer changes keyboard focus behavior.

<Canvas of={AccordionStories.Horizontal} />

### Events

An interaction first emits Item `onOpenChange` with `{ open, eventDetails }`, then Root
`onValueChange` with `{ value, eventDetails }`, using the same event details. Either handler can
cancel before commit. Changes to the controlled value and single-mode sibling closure do not emit
Item requests.

<Canvas of={AccordionStories.Events} />

### Controlled

Use `[(value)]` to accept array requests. Cancel a request in `onValueChange` to keep the current selection.

<Canvas of={AccordionStories.Controlled} />

### Keep mounted

With `keepMounted`, collapsed panels keep their element in the DOM while hidden — useful to preserve
form state. Use `hiddenUntilFound` instead to keep collapsed content discoverable by the browser's
find-in-page (it renders `hidden="until-found"`).

<Canvas of={AccordionStories.KeepMounted} />

## API Reference

### Root

`RdxAccordionRootDirective` — groups all parts and owns the expanded value. Apply to a container element (typically a `<div>`).

`value`, `defaultValue`, and event values are arrays in both modes, for example
`[defaultValue]="['one']"`. A supplied `value` (including `[]`) owns selection; use `[(value)]`
to accept requests automatically, or update `[value]` in a request handler. Without `value`, Root
snapshots `defaultValue` once. Later default changes do not reset selection.

<ArgTypes of={RdxAccordionRootDirective} />

**Data attributes**

| Attribute          | Present when                                |
| ------------------ | ------------------------------------------- |
| `data-orientation` | Always — `"horizontal"` \| `"vertical"`.    |
| `data-disabled`    | The accordion is disabled.                  |

### Item

`RdxAccordionItemDirective` — groups a header with its panel. Apply to a container element (typically a `<div>`).

Item values use reference/value identity and can be objects, functions or arrays. An array item
remains a single value. Omitted or nullish values receive a stable generated identity.

<ArgTypes of={RdxAccordionItemDirective} />

**Data attributes**

| Attribute       | Present when                            |
| --------------- | --------------------------------------- |
| `data-open`     | The item is open.                       |
| `data-closed` | The item is closed. |
| `data-hidden` | The item is closed and its exit has finished. |
| `data-orientation` | Always — `"horizontal"` \| `"vertical"`. |
| `data-disabled` | The item is disabled.                   |
| `data-index`    | Always — the item's zero-based index.   |

### Header

`RdxAccordionHeaderDirective` — the heading that labels the panel. Reads everything from context, so it takes no inputs. Apply to a heading element (typically an `<h3>`).

**Data attributes**

| Attribute       | Present when                            |
| --------------- | --------------------------------------- |
| `data-open`     | The item is open.                       |
| `data-closed` | The item is closed. |
| `data-hidden` | The item is closed and its exit has finished. |
| `data-orientation` | Always — `"horizontal"` \| `"vertical"`. |
| `data-disabled` | The item is disabled.                   |
| `data-index`    | Always — the item's zero-based index.   |

### Trigger

`RdxAccordionTriggerDirective` — the button that toggles the panel. Apply to a native `<button>`
element, or a non-native host for which Button supplies role, tab order and Enter/Space activation.
Native buttons default to `type="button"`; authored `submit` and `reset` types are preserved.
Disabled native buttons use native `disabled`; disabled non-native hosts use `aria-disabled`
and leave the Tab order. Root, Item and local Trigger `disabled` combine.

The composed Button inputs are `disabled`, `type`, `tabIndex` and `role`. `id` registers the authored
Trigger identity for the Panel label, and updates or unregisters with the part.

<ArgTypes of={RdxAccordionTriggerDirective} />

**Data attributes**

| Attribute         | Present when                |
| ----------------- | --------------------------- |
| `data-panel-open` | The item's panel is open.   |
| `data-index` | Always — the item's zero-based index. |
| `data-orientation` | Always — `"horizontal"` \| `"vertical"`. |
| `data-hidden` | The item is closed and its exit has finished. |
| `data-disabled`   | The item is disabled.       |

### Panel

`RdxAccordionPanelDirective` — the collapsible content. Apply to a container element (typically a `<div>`).

`id`, `keepMounted`, and `hiddenUntilFound` are exposed from Collapsible Panel. Panel boolean
policies override Root, including explicit `false`; `undefined` restores reactive inheritance.
Findable panels remain mounted even when `keepMounted` is false. `beforematch` requests expansion
through Item and Root; canceled or unaccepted controlled requests restore the hidden state.

Closed default panels currently detach their native host while retaining Angular children.
Use `keepMounted` to retain the closed host; complete child-view disposal is tracked in
[the Accordion parity matrix](https://github.com/radix-ng/primitives/blob/main/packages/primitives/accordion/PARITY.md).

<ArgTypes of={RdxAccordionPanelDirective} />

**Data attributes**

| Attribute             | Present when                            |
| --------------------- | --------------------------------------- |
| `data-open`           | The panel is open.                      |
| `data-closed` | The panel is closed. |
| `data-hidden` | The item is closed and its exit has finished. |
| `data-orientation`    | Always — `"horizontal"` \| `"vertical"`.|
| `data-disabled`       | The item is disabled.                   |
| `data-index`          | Always — the item's zero-based index.   |
| `data-starting-style` | The panel is entering, or closed and retained for browser search. |
| `data-ending-style`   | The panel is animating out.             |

**CSS variables**

| Variable                     | Description                                         |
| ---------------------------- | --------------------------------------------------- |
| `--accordion-panel-height`   | The panel's measured height, for height animations. |
| `--accordion-panel-width`    | The panel's measured width, for width animations.   |

## Accessibility

Accordion reuses native button semantics and adds expansion and label relationships for the
[APG Accordion pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/).
See the library's [accessibility guidance](?path=/docs/overview-accessibility--docs).

| Area | Implementation | Reference |
| --- | --- | --- |
| Semantics | Heading hosts contain buttons; region Panels are labelled by their Trigger. | [APG roles](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/#wai-ariaroles,states,andproperties), [WCAG 4.1.2](https://www.w3.org/TR/WCAG22/#name-role-value) |
| Keyboard | Native activation or shared Button Enter/Space handling. | [APG keyboard](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/#keyboardinteraction), [WCAG 2.1.1](https://www.w3.org/TR/WCAG22/#keyboard) |
| Focus | Normal browser Tab order; disabled triggers leave that order. | [WCAG 2.4.3](https://www.w3.org/TR/WCAG22/#focus-order) |
| State | Trigger exposes `aria-expanded` and open-only `aria-controls`. | [WCAG 4.1.2](https://www.w3.org/TR/WCAG22/#name-role-value) |

### Keyboard Interactions

| Key | Description |
| --- | --- |
| `Enter` / `Space` | Toggles the focused enabled item. Space activates on release. |
| `Tab` / `Shift` + `Tab` | Moves through enabled triggers in browser tab order. |

`Arrow*`, `Home`, and `End` do not move focus. `loopFocus` and orientation-driven focus behavior
are deprecated no-ops.
