# @radix-ng/primitives/select

Secondary entry point of `@radix-ng/primitives`. It can be used by importing from `@radix-ng/primitives/select`.

See the [versioned Base UI compatibility audit](./PARITY.md) for supported contracts, Angular
adaptations, regression coverage and remaining gaps. The
[typed wrapper example](./stories/select-typed-control.ts) demonstrates application-owned markup
with inherited form bindings and events.
