# Slider

#### An input where the user selects a value, or a range of values, from within a given range.

<Canvas sourceState="hidden" of={SliderStories.Default} />

## Features

- ✅ Can be controlled or uncontrolled.
- ✅ Single value or multiple thumbs for a range.
- ✅ Configurable thumb collision behavior (`push`, `swap`, `none`).
- ✅ Minimum distance between thumbs.
- ✅ Press or drag anywhere on the control to update the value.
- ✅ Thumb alignment modes: `center`, `edge`, and `edge-client-only`.
- ✅ Horizontal and vertical orientation, with RTL support.
- ✅ Value formatting with `Intl.NumberFormat`.
- ✅ Full keyboard navigation, including large steps.
- ✅ Works with Angular forms via a hidden native range input per thumb.

## Anatomy

The slider is assembled from directive-based parts — there are no separate
horizontal/vertical components. The same parts drive both orientations, switched
through the `orientation` input on the root.

```html
<div rdxSliderRoot>
    <div rdxSliderLabel>Volume</div>
    <output rdxSliderValue></output>
    <div rdxSliderControl>
        <div rdxSliderTrack>
            <div rdxSliderIndicator></div>
            <div rdxSliderThumb>
                <input rdxSliderThumbInput />
            </div>
        </div>
    </div>
</div>
```

Each thumb owns a nested `input[rdxSliderThumbInput]`. It is visually hidden but
remains the focusable element that powers keyboard interaction, accessibility and
form submission.

Use `rdxSliderLabel` inside the root to name the group. In a single-thumb slider, clicking the label
focuses the native input. In a range slider, give each input a distinct name with `aria-label` or
`aria-labelledby`, such as “Minimum” and “Maximum”.

## Value and reset

Use `defaultValue` to seed an uncontrolled slider. The initial `min` seeds the value when no default
is provided. Later bounds constrain the rendered and submitted values without emitting change
events. An accepted native form reset restores the initial uncontrolled value or delegates to the
bound Reactive Forms control.

Values supplied between steps are preserved in the native input and in form submissions. The next
keyboard or pointer edit uses the configured step grid.

Use `[(value)]` for an editable Angular model and `[formField]` for Signal Forms. To accept, ignore,
or delay each proposal from a parent component, bind `[controlledValue]` and update it from
`onValueChange`. The parent-owned value stays in effect across native resets. An explicit `0` is a
value, `null` displays the current minimum, and an empty array has no thumb values to submit.

## Change events

`onValueChange` emits `{ value, eventDetails }`, where `value` is a number for a single slider or a
number array for a range slider. The change details match Base UI's cancellable change contract:
`reason`, `event`, `trigger`, `activeThumbIndex`, `cancel()`, `allowPropagation()`, and
`isCanceled()`. The emitted event is cloned so `event.target.value` and `event.target.name` contain
the candidate slider value and root `name`.

`onValueCommitted` emits `{ value, eventDetails }` when an interaction commits. Its details include
the commit `reason`, originating event, and trigger. This is a generic event like Base UI, so it is
not cancelable and does not include `activeThumbIndex`.
Controlled sliders report the last uncanceled proposal on commit. Disabling the pressed thumb or
the whole slider during a drag ends the gesture without committing.

```html
<div [controlledValue]="value()" (onValueChange)="setValue($event)" rdxSliderRoot>
    ...
</div>
```

```ts
setValue(change: RdxSliderValueChangeEvent) {
    if (this.isLocked()) {
        change.eventDetails.cancel();
        return;
    }

    this.value.set(change.value);
}
```

## Thumb alignment

`thumbAlignment="center"` aligns each thumb's center with the Track endpoints. Both edge modes
inset the thumbs so their outer edges meet the Track endpoints. The indicator runs between the
thumb centers in a range. Control defines the pointer hit area. Its padding and border can extend
past the Track without changing where thumbs stop. For server-rendered `edge`, an inline script measures and positions the parts before
hydration. The script uses Angular's `CSP_NONCE` when provided. In `edge-client-only`, the parts
become visible after client measurement.

### Reactive forms

The root implements `ControlValueAccessor`, so it binds directly to
`formControl` / `formControlName` and `[(ngModel)]`.

Inside a Field, Slider inherits the Field's `name` and disabled state, including disabled Fieldsets.
Field labels name the group, and Field descriptions and visible errors describe the native thumbs.
Give each thumb its own accessible name in a range. Use `rdxNgControlField` to display Reactive
Forms validation through the Field. Focus can move between thumbs without triggering blur
validation. The field is marked touched when focus leaves the slider.

## Accessibility

Adheres to the [Slider WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/slider-multithumb).

### Keyboard Interactions

| Key | Description |
| --- | ----------- |
| `ArrowRight` / `ArrowUp` | Increases the value of the focused thumb by one step. In RTL horizontal mode, `ArrowRight` decreases instead. |
| `ArrowLeft` / `ArrowDown` | Decreases the value of the focused thumb by one step. In RTL horizontal mode, `ArrowLeft` increases instead. |
| `Shift` + `ArrowRight` / `ArrowUp` | Increases the value of the focused thumb by one large step. |
| `Shift` + `ArrowLeft` / `ArrowDown` | Decreases the value of the focused thumb by one large step. |
| `PageUp` | Increases the value of the focused thumb by one large step. |
| `PageDown` | Decreases the value of the focused thumb by one large step. |
| `Home` | Sets the focused thumb to the minimum value (or the preceding thumb's value plus the minimum gap for range sliders). |
| `End` | Sets the focused thumb to the maximum value (or the following thumb's value minus the minimum gap for range sliders). |
