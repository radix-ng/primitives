## State ownership and defaults

Ownership class for this entry: **Several ownership contracts**. The [shared contract](../../../docs/engineering/state-ownership.md)
distinguishes controlled UI requests, editable form models, readonly configuration, native DOM state
and derived/render state. Local writes to required form models are legitimate Angular behavior.
For strict controlled UI state, a request must not mutate the effective value before parent acceptance.

| State field / source                                 | Current declaration                  | Ownership review                                                                                               |
| ---------------------------------------------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| [`RdxComboboxChip.value`](src/combobox-chip.ts)      | `input.required<AcceptableValue>()`  | Readonly supplied data/identity/configuration; no local model write.                                           |
| [`RdxComboboxItem.value`](src/combobox-item.ts)      | `input.required<AcceptableValue>()`  | Readonly supplied data/identity/configuration; no local model write.                                           |
| [`RdxComboboxRoot.value`](src/combobox-root.ts)      | `model<ComboboxValue \| null>(null)` | Editable form model where the actual Angular control contract requires it; coordinate CVA/native/Signal Forms. |
| [`RdxComboboxRoot.inputValue`](src/combobox-root.ts) | `model<string>('')`                  | Editable form model where the actual Angular control contract requires it; coordinate CVA/native/Signal Forms. |
| [`RdxComboboxRoot.open`](src/combobox-root.ts)       | `model<boolean>(false)`              | Define parent-owned UI requests separately from accepted/effective state; no form-model exemption is implied.  |

| Declared default / source                              | Declaration                               | Required comparison                                                                                                                                         |
| ------------------------------------------------------ | ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`RdxComboboxRoot.defaultValue`](src/combobox-root.ts) | `input<ComboboxValue \| null>(undefined)` | Initial supplied/falsy/empty/form priority, initial-only snapshot, late changes and reset baseline. Distinguish state defaults from reactive configuration. |
| [`RdxComboboxRoot.defaultOpen`](src/combobox-root.ts)  | `input(false)`                            | Initial supplied/falsy/empty/form priority, initial-only snapshot, late changes and reset baseline. Distinguish state defaults from reactive configuration. |

Always include allowed `false`, `0`, `''`, `[]` and `null` cases; initial parent/CVA/Signal Forms
writes; default changes after initialization; ignored/delayed/replaced controlled requests; cancellation
and native/form reset. Not every case applies to readonly or infrastructure entries: mark those
boundaries explicitly instead of converting all models to readonly inputs.

## Family-specific comparison matrix

“Source” identifies a local implementation fact. “Compare/verify/audit” is pending work. Priorities
describe the target work, not a certificate or a reproduced defect count.

are permitted; changed observable behavior needs evidence or an explicitly reviewed deviation.
