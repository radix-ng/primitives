# Field

#### Groups a control with accessible label, description, error message, and field state.

Field groups a control's accessible metadata and decides when to display validity. Angular Forms
integrations use the `rdxNgControlField` and `rdxSignalField` adapters.

<Canvas sourceState="hidden" of={FieldStories.Default} />

## Features

- ✅ Wires labels to controls with `for` and generated control ids.
- ✅ Wires descriptions and errors with `aria-describedby`.
- ✅ Exposes state via `data-invalid`, `data-disabled`, `data-required`, `data-dirty`, `data-touched`, `data-filled`, and `data-focused`.
- ✅ Works with native controls and custom controls.
- ✅ Bridges Reactive Forms and `ngModel` without repeated state bindings.
- ✅ Matches errors by native constraint or Angular validation key.
- ✅ Inherits disabled state from the enclosing Fieldset.

## Import

```typescript
import {
  RdxFieldRoot,
  RdxFieldLabel,
  RdxFieldControl,
  RdxFieldDescription,
  RdxFieldError,
  RdxFieldValidity,
  RdxNgControlField
} from '@radix-ng/primitives/field';
```

## Anatomy

```html
<div rdxFieldRoot>
  <label rdxFieldLabel>Label</label>
  <input rdxFieldControl />
  <p rdxFieldDescription>Description</p>
  <p rdxFieldError>Error</p>
</div>
```

For a plain native `rdxFieldControl`, use the browser's constraints such as `required`, `type="email"`,
or `pattern`. An enclosing `rdxFormRoot` checks those constraints on submit and focuses the first
invalid control. Set `match="valueMissing"` or `match="typeMismatch"` to describe a specific native
constraint. An Angular Forms adapter supplies validation when it owns the control's invalid state.

For a checkbox or radio group where each control needs its own label and description, wrap each one in a
`rdxFieldItem`. The item scopes the label / description / control association to its control while
reflecting the field's validation state; its `disabled` is OR'd with the root's.

```html
<div rdxFieldRoot>
  <div rdxFieldItem>
    <label rdxFieldLabel>Option A</label>
    <input rdxFieldControl type="radio" />
    <p rdxFieldDescription>Description A</p>
  </div>
  <div rdxFieldItem>
    <label rdxFieldLabel>Option B</label>
    <input rdxFieldControl type="radio" />
  </div>
  <p rdxFieldError>Error</p>
</div>
```

### Reactive Forms

Place `rdxNgControlField` next to `formControl`, `formControlName`, or `ngModel`. Angular Forms remains
responsible for validation; the adapter reports actual state while Field's `validationMode` controls when
it becomes visible. Use `rdxFieldError[match]` for a specific Angular error key.

```html
<div rdxFieldRoot required>
  <label rdxFieldLabel>Email</label>
  <input formControlName="email" rdxFieldControl rdxNgControlField />
  <p match="required" rdxFieldError>Email is required.</p>
  <p match="email" rdxFieldError>Enter a valid email address.</p>
</div>
```

## API Reference

An explicit `dirty` or `touched` on Root controls display timing when the Field adapter leaves that
state unowned. Fieldset, Root, and the adapter can each disable a field. Control can also
declare its own `required` and `disabled` inputs.

`rdxFieldLabel` associates a native label with the registered control. Set its `for` input to name a
different control explicitly. A non-native label can name and focus a custom Field Control.
On Control, `aria-describedby` merges authored IDs with mounted descriptions and visible errors.
Use `aria-labelledby` or `aria-label` to supply an authored name.

### Validity

`RdxFieldValidity` exposes a read-only `state()` with `valid`, `pending`, and the displayed
`messages`. `valid` is `null` while presentation is neutral. Use `matchesError(key)` to test a
displayed native constraint or Angular error key. Apply it to an `ng-container` inside Field
to use the reference in a template without adding a DOM element.

```html
<ng-container rdxFieldValidity #validity="rdxFieldValidity">
  @if (validity.state().valid === false) {
    <p rdxFieldError>{{ validity.state().messages.join(' ') }}</p>
  }
</ng-container>
```

Field and Form default to `onBlur`. Use `validationMode="onSubmit"` to keep client validity neutral
until the first submit attempt. A disabled Field hides automatic Error parts. Bind `[match]="true"`
for explicitly controlled visibility.

## Data attributes

Each part exposes its own subset. Presence attributes have an empty string value when present.

| Attribute       | Parts                                                                            | Present when                                                         |
| --------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| `data-invalid`  | RdxFieldRoot, RdxFieldItem, RdxFieldControl, RdxFieldLabel, RdxFieldDescription                | Displayed validation is invalid.                 |
| `data-invalid`  | RdxFieldError                                                                               | The error is visible and the field is invalid.   |
| `data-valid`    | RdxFieldRoot, RdxFieldItem, RdxFieldControl, RdxFieldLabel, RdxFieldDescription, RdxFieldError | Displayed validation is valid.                   |
| `data-disabled` | RdxFieldRoot, RdxFieldItem, RdxFieldControl, RdxFieldLabel, RdxFieldDescription, RdxFieldError | The field, item, or control is disabled.         |
| `data-required` | RdxFieldRoot, RdxFieldItem, RdxFieldControl, RdxFieldLabel                                    | The field or control is required.               |
| `data-dirty`    | RdxFieldRoot, RdxFieldItem, RdxFieldControl, RdxFieldLabel, RdxFieldDescription, RdxFieldError | The control value has changed.                   |
| `data-touched`  | RdxFieldRoot, RdxFieldItem, RdxFieldControl, RdxFieldLabel, RdxFieldDescription, RdxFieldError | The control has been touched.                    |
| `data-filled`   | RdxFieldRoot, RdxFieldItem, RdxFieldControl, RdxFieldLabel, RdxFieldDescription, RdxFieldError | The control contains a value.                    |
| `data-focused`  | RdxFieldRoot, RdxFieldItem, RdxFieldControl, RdxFieldLabel, RdxFieldDescription, RdxFieldError | The control is focused.                          |
