# Progress

#### Displays task completion with accessible label, value, track, and indicator parts.

<Canvas sourceState="hidden" of={ProgressStories.Default} />

## Features

- ✅ Supports determinate and indeterminate progress.
- ✅ Supports custom `min` and `max` ranges.
- ✅ Provides Label and Value parts for accessible naming and value text.
- ✅ Exposes state through boolean `data-complete`, `data-progressing`, and `data-indeterminate` attributes.

## Import

```typescript
import {
  RdxProgressRootDirective,
  RdxProgressLabelDirective,
  RdxProgressValueDirective,
  RdxProgressTrackDirective,
  RdxProgressIndicatorDirective
} from '@radix-ng/primitives/progress';
```

## Anatomy

```html
<div rdxProgressRoot [value]="70">
  <span rdxProgressLabel>Upload progress</span>
  <span rdxProgressValue></span>
  <div rdxProgressTrack>
    <div rdxProgressIndicator></div>
  </div>
</div>
```

## API Reference

The three status attributes below are shared by every part; the per-part tables list the additional
attributes each one exposes.

| Attribute            | Parts                                | Present when                          |
| -------------------- | ------------------------------------ | ------------------------------------- |
| `data-complete`      | Root, Label, Value, Track, Indicator | The value has reached `max`.          |
| `data-progressing`   | Root, Label, Value, Track, Indicator | The determinate value is below `max`.   |
| `data-indeterminate` | Root, Label, Value, Track, Indicator | The value is unknown or non-finite.    |

### Root

`RdxProgressRootDirective` — applies `role="progressbar"` and the ARIA value attributes. Apply to a
container element (typically a `<div>`).

<ArgTypes of={RdxProgressRootDirective} />

The default value text is the localized percentage. `format` formats the clamped value with
`Intl.NumberFormat`, and `valueLabel` can supply custom visible text. Use `getAriaValueText` to
derive a separate accessible value from that text and the original supplied value. The formatted
argument is empty when the value is indeterminate. An explicit `aria-valuetext` takes precedence.

**Data attributes**

| Attribute    | Value                                          |
| ------------ | ---------------------------------------------- |
| `data-value` | The current value (absent when indeterminate). |
| `data-min`   | The minimum value.                             |
| `data-max`   | The maximum value.                             |

### Label

`RdxProgressLabelDirective` — gives the progressbar its accessible name through `aria-labelledby`.
Apply it to the text element that names the progressbar. Its `id` defaults to the Root's `labelId`.
It exposes the three shared status attributes.

<ArgTypes of={RdxProgressLabelDirective} />

### Value

`RdxProgressValueDirective` — displays the formatted value text. It is `aria-hidden` because the value
is already announced via the root's `aria-valuenow` / `aria-valuetext`.

**Data attributes**

| Attribute    | Value                                          |
| ------------ | ---------------------------------------------- |
| `data-value` | The current value (absent when indeterminate). |
| `data-min`   | The minimum value.                             |
| `data-max`   | The maximum value.                             |

### Track

`RdxProgressTrackDirective` — contains the visual indicator and mirrors the root state attributes.

**Data attributes**

| Attribute    | Value                                          |
| ------------ | ---------------------------------------------- |
| `data-value` | The current value (absent when indeterminate). |
| `data-min`   | The minimum value.                             |
| `data-max`   | The maximum value.                             |

### Indicator

`RdxProgressIndicatorDirective` — displays the visual progress fill.
An HTML Indicator inherits the Track height and sets its width from the normalized percentage,
anchored at the inline start. Use CSS to size and animate the indeterminate fill. For SVG, use
the percentage to drive the stroke geometry.

**Data attributes**

| Attribute      | Value                                                  |
| -------------- | ------------------------------------------------------ |
| `data-value`   | The current value (absent when indeterminate).         |
| `data-min`     | The minimum value.                                     |
| `data-max`     | The maximum value.                                     |
| `data-percent` | The completion percentage (absent when indeterminate). |

## Accessibility

The root uses `role="progressbar"`. An explicit `aria-labelledby` takes precedence over the
mounted `rdxProgressLabel`. Use `aria-label` to name a bar with no associated label.
The value is conveyed through `aria-valuenow` and `aria-valuetext`, so
`rdxProgressValue` is `aria-hidden`. In the indeterminate state `aria-valuenow` is omitted while
`aria-valuemin` / `aria-valuemax` remain and `aria-valuetext` announces `"indeterminate progress"`.
