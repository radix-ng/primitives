# Label

#### An optional directive for a native label.

<Canvas sourceState="hidden" of={LabelDirectiveStories.Default} />

## Choosing a label

Use a native `<label>` with a matching `for` and control `id`, or wrap the control in its label.
Inside `rdxFieldRoot`, use `rdxFieldLabel` to associate the label with the registered control automatically.

Apply `rdxLabel` to a native `<label>` when you want a generated label ID, its `htmlFor` input, or
double-click text selection protection. The directive supports native label association and activation.

## Import

Import the directive when using `rdxLabel`.

```typescript
import { RdxLabelDirective } from '@radix-ng/primitives/label';
```

## Examples

### Using the directive

```html
<label rdxLabel htmlFor="uniqId">First name</label>
<input class="Input" id="uniqId" type="text" />
```

## Accessibility

The browser provides the accessible name and click activation through the native label association.
Use a labelable element, such as a native `button` or `input`, as the associated control.
